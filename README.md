# Likud — новый сайт

Современный сайт партии **Ликуд** (הליכוד) на трёх языках: иврит (RTL), английский, русский.

## Что внутри

- **`Likud - Сайт.html`** — рабочий прототип сайта с навигацией (главная, о партии, руководство, позиции, новости, отделения, контакты).
- **`Likud - Дизайн-концепт.html`** — документ дизайн-концепции (подход, IA, дизайн-система, RTL-гайд).
- `app.jsx`, `sections-*.jsx`, `shared.jsx`, `tweaks-panel.jsx` — React-компоненты (рендерятся через Babel в браузере).
- `images/` — логотипы (`logo.svg`, `logoEN.svg`, `logoRU.svg`) и фото лидера партии (`netanyahu.jpg`).
- `PROMPT_FOR_CLAUDE_DESIGN.md` — исходный бриф на дизайн.

## Запуск локально

Сайт — статический, но из-за JSX через Babel и кросс-файловых скриптов его нужно открывать через HTTP-сервер, а не file://.

```bash
cd "Ликуд сайт"
python3 -m http.server 8080
# открыть http://localhost:8080/Likud%20-%20Сайт.html
```

## Стек концепции

- React 18 (через CDN) + Babel standalone — для прототипа.
- Шрифты: **Heebo** (иврит), **Rubik** (латиница, кириллица).
- Палитра: `#0038B8` (синий израильского флага), `#002A6E` (deep), `#001541` (ink), `#C8102E` (red accent).

Для продакшна план — Next.js (App Router) + TypeScript + Tailwind + next-intl.
